# LayUp Technologies

> LayUp is a South African lay-by / "Save Now, Buy Later" payment platform. Merchants let customers reserve goods with a deposit and pay the balance in scheduled instalments (weekly or monthly) before delivery — no credit, no interest. LayUp schedules payments, holds inventory, and settles merchants when orders complete. The REST API (apikey header auth) covers merchants, orders, order amendments, payment plans, payments, cards, DebiCheck, EFT, PayAt, invoices, and settlements, plus order and payment webhooks.

## Authentication
- API-key based. Pass the key in the `apikey` HTTP header on every request.
- Sandbox base URL: https://sandbox-api.layup.co.za
- Production base URL: https://api.layup.co.za
